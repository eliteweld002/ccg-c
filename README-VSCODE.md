# Canada Compressed Gas Corporation

Full project export of Sites version 15.
Source commit: 66b232fa1abc9032dd868ae86aa9b41f2080c805

## Open in VS Code
1. Extract this ZIP.
2. In VS Code, select File > Open Folder and choose canada-compressed-gas.
3. Install Node.js and pnpm if they are not already installed.
4. In the VS Code terminal, run:

```sh
pnpm install
pnpm dev
```

Open the localhost URL printed in the terminal (usually http://localhost:3000).

## Included
- Next.js / React / TypeScript source, styling, components, and configuration
- Original images and public assets
- Dependency manifest and pnpm lockfile
- Run pnpm build to regenerate the static export in out/
- Contact API source, tests, and deployment documentation

Dependencies (node_modules) and Git history are not included; pnpm install restores dependencies.
Secrets and hosted runtime data are not part of this source export.
See docs/vercel-launch.md for contact form deployment and email configuration.
